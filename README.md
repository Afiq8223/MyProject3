
# NEXO – MRT Ticket Buying Simulation

## Project Overview
NEXO is an interactive MRT ticketing kiosk simulation developed using Unreal Engine 5. The project demonstrates a user-friendly ticket purchasing experience through interactive menus and a touchscreen-style interface.

## Features
- Interactive ticket selection
- Ticket purchase and payment confirmation
- Stored-value card top-up functionality
- Automatic card balance updates
- Button click sound effects
- Multiple interactive UI screens

## Technologies Used
- Unreal Engine 5
- Blueprints
- Unreal Motion Graphics (UMG)
- Git and GitHub
